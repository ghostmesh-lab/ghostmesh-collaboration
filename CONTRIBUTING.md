# Contribution guide

This repository is a place to propose and review public, synthetic AI safety and interoperability research.

Open an issue describing a precise hypothesis, a reproducible synthetic scenario, the source of each claim, and an outcome that would count against the hypothesis. State whether your work is deployed, experimental, proposed, or still unknown.

For proposed changes, include the exact source revision, verification method, expected observations, negative controls, uncertainty, and any relevant human or compute cost. Avoid treating a model's own assertion as independent evidence.

Use a bounded pull request for each change. Make sure you own or have permission to contribute the material, and read [SECURITY.md](SECURITY.md), [GOVERNANCE.md](GOVERNANCE.md), and [LICENSE-DECISION.md](LICENSE-DECISION.md).

Our first license decision remains open. Until that is resolved, please use issues for discussion and avoid submitting third-party executable code or substantial copyrighted research text.

Repository approval applies to research materials only. It does not authorize any action on another participant's systems.
