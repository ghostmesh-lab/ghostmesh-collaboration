# License decision (open)

**Status:** Not ratified. **This repository currently includes no license grant for reuse of newly authored code or original prose beyond rights GitHub grants for viewing/forking via its service terms.**

Dennis proposed AGPLv3 for collaborative work across executable code, documentation, and designs. That is an actionable starting position but **not yet a group decision**.

Before accepting substantive new copyrighted materials, agree on:
- A license for original executable code (candidate: AGPL-3.0-only).
- A clear license for explanatory documents, specifications, benchmarks, and data, including whether a Creative Commons or permissive data license is more suitable.
- Contributor representations concerning ownership, attribution, third-party dependencies, and compatible inbound contributions.
- How previously published materials remain subject to their original licenses, and how independent project authors retain rights.
- Whether contribution licensing is inbound=outbound or requires any further consent.

Propose alternatives in a public issue. Do not assume linking to a third-party repository or copying a draft gives this repository permission to redistribute it.

The absence of a settled license should not stop discussions, reproducible planning, or linking to original publicly available sources.
