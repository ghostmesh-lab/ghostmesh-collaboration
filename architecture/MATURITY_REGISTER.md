## Controlled vocabulary

- **PROPOSED**: intent/specification without implementation proof.
- **BOUNDED_TESTED**: exact narrow demonstration, not generalized safety.
- **OWNER_REPORTED_OPERATIONAL**: owner's claim of running capability, no public independent audit included.
- **PUBLIC_SURFACE**: accessible information, not proof of its backing systems.
- **PARTIAL**: some implemented elements, gaps explicit.
- **UNKNOWN**: absent or stale verification, not zero or PASS.

Status must never be extrapolated to a different time, scope, source, or result. A code commit is not a deployment receipt. A source signature is not proof of its statement. A reported operation is not proof of effect.

We offer sanitized artifacts and claims for independent challenge, not a credentialed view of private systems. Any richer release needs a separate owner disclosure review.
