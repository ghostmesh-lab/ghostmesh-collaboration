# GhostMesh Collaboration Lab

**Public, independent research into evidence, belief, authority, outcomes, and repair across AI systems.**

This repository lets independently governed systems compare methods using synthetic test cases, source references, honest uncertainty, and reproducible results. It is a research exchange, **not** an operational federation, shared authority, endorsed standard, or binding partnership.

## Questions we are exploring

- What was actually observed, and how many independent sources support it?
- Which beliefs are inferred, contradicted, obsolete, or still unknown?
- Which agent, role, policy, and delegation authorized an action?
- What actually happened, as distinct from what the tool or agent reported?
- Who can challenge a harmful objective or authorize consequential remediation?

A valid signature does not prove a claim is true. A successful execution report does not establish its intended result. A permitted action is not automatically a defensible objective.

## Boundary

The repository contains publicly shareable explanations and purely synthetic experiments. It shares no private source, operational configurations, endpoints, secrets, identity keys, credentials, telemetry, or data. GitHub participation conveys no privilege over anyone's systems. Each contributor retains ownership of its own environment and must authorize any real-world action separately.

**Licensing is being discussed**. Do not add third-party code or substantial copyrighted text until the license and permission questions are resolved. Public issues are welcome for discussion now.
